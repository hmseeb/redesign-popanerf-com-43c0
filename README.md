# Pop-A-Nerf Entertainment — Website Redesign

A complete, from-scratch redesign of popanerf.com: a bold, modern, mobile-first site for a
mobile Nerf war entertainment company that builds fully enclosed battle arenas at the
customer's location.

## Stack

Vanilla HTML, CSS and JavaScript — no build step, no dependencies. Open `index.html` or serve
the folder with any static server:

```bash
python3 -m http.server 8000
```

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Entire page: semantic markup, meta/OpenGraph tags, JSON-LD business schema |
| `styles.css` | Design system (custom properties), layout, components, responsive rules |
| `script.js` | Mobile nav, sticky header, scroll reveal, scroll-spy, live event estimator |
| `favicon.svg` | Scalable favicon |

## Sections

1. **Hero** — business name, tagline and primary booking CTAs
2. **The Experience** — enclosed arena, full armory, dedicated referee, zero downtime
3. **Where We Set Up** — parks, back yards, corporate events, youth groups (links to galleries)
4. **What's Included** — the full standard event package checklist
5. **Pricing** — all six group-size tiers plus a live event estimator using real upgrade prices
6. **Upgrades** — twelve add-ons with real descriptions and prices
7. **Catering** — the Domino's Pizza partnership
8. **Reviews** — link to the company's Google reviews
9. **Contact** — phone, online booking, service note and the Spanish-language site

## Content & imagery

All copy, prices, links and the phone number come from the live Pop-A-Nerf Entertainment site.
Every photo is an authentic image from the business (arenas, events, upgrades, logo) — no
stock photography was substituted.
